# Rick & Morty Character Explorer 🛸

A web app to browse, search, and filter characters from the Rick & Morty universe.

## 🔗 Live Site

[rick-morty-app-heryan.netlify.app](https://rick-morty-app-heryan.netlify.app/)

## 📋 About

This app consumes the public Rick & Morty REST API to fetch and display characters
dynamically. Built to practice React fundamentals including hooks, state management,
and API integration.

## ✨ Features

- Fetch and display characters from the Rick & Morty REST API
- Filter characters by name, status, and species
- Dynamic rendering with React hooks
- Responsive design
- Deployed on Netlify

## 🛠️ Built With

- [React](https://react.dev/)
- [Vite](https://vitejs.dev/)
- [Rick & Morty API](https://rickandmortyapi.com/)
- Deployed on [Netlify](https://netlify.com/)

## 🚀 Getting Started
```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
